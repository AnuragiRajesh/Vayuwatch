# Vayuwatch

Vayuwatch is a Flutter application that provides weather-related monitoring and alerts. It targets mobile and desktop platforms via Flutter.

## Features
- Real-time weather data
- Cross-platform (Android, iOS, Linux, macOS, Windows, Web)

## Requirements
- Flutter SDK (stable)
- Android SDK / Xcode (for mobile builds)

## Quick start
1. Install Flutter: https://flutter.dev/docs/get-started/install
2. Fetch dependencies:

```bash
flutter pub get
```

3. Run on a connected device or emulator:

```bash
flutter run
```

4. Build release APK (Android):

```bash
flutter build apk --release
```
